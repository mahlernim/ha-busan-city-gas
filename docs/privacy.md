# 개인정보와 권한

[처음으로](../README.md)

## 어떤 정보가 필요한가요?

SK E&S·삼천리·대성·해양에너지 로그인에는 회원 아이디·비밀번호를 사용합니다. 가스앱은 성명·휴대폰 번호·생년월일·성별 코드·통신사와 SMS 인증번호로 본인 인증하며, 인증된 세션을 HA 설정에 보관합니다. 인증 입력은 본인 인증 처리에 사용됩니다. 계약 정보, 고지서, 검침 기간·접수 내역을 조회하여 Home Assistant에 보관합니다.
센서를 연결하면 기준 검침값, 센서값, 보정 이력도 저장합니다.
센서 없는 추정은 계약별 모델 기준점과 최근 90일의 실제 관측을 별도로 저장합니다. 같은 날짜의 학습용 관측은 마지막 입력으로 대체합니다. 이 자료도 HA 설정·백업의 일부이며 개발자에게 전송되지 않습니다.

로그인과 공식 정보 조회를 위해 필요한 정보는 선택한 도시가스 공급사 또는 가스앱·본인 인증 서비스로 전송됩니다.
제출을 승인하거나 자동 제출을 별도로 켜면 계약·계량기 정보와 정수 검침값도 선택한 도시가스 공급사로 전송됩니다.
휴대폰 알림을 켜면 검침값과 알림 문구가 Home Assistant Companion App의 알림 경로로 전달됩니다.
이 통합 개발자가 별도 서버로 계정 정보나 사용 기록을 수집하지는 않습니다.

## 저장소가 암호화되나요?

Home Assistant 설정 저장소는 별도의 암호화 금고가 아닙니다. 설정 폴더와 백업에 접근할 수 있는 사람을 제한하세요.
비밀번호·쿠키를 화면이나 로그·진단 결과에 노출하지 않도록 처리하지만, 공개 제보 전에는 첨부 내용을 직접 확인해 주세요.
홈페이지 원본 HTML이나 로그인 응답을 파일로 보관하지 않습니다.

## 누가 보정할 수 있나요?

관리자와 알림 수신자로 지정한 휴대폰에 연결된 HA 사용자가 해당 계약을 조회·보정할 수 있습니다.
수신자를 추가할 때에는 그 사람에게 이 권한을 부여하는지 확인해 주세요. 설정 변경과 전체 공식 정보 새로고침은 관리자만 할 수 있습니다.

## 공개 제보 시 주의

비밀번호, 인증 토큰, 쿠키, 계약번호, 주소, 원본 고지서, 원본 진단 파일을 공개 게시물에 올리지 마세요.
문제 설명과 개인정보를 가린 화면 문구만으로 먼저 제보해 주세요.

가스앱 서비스 가입과 접수 채널 변경은 전용 화면에서 별도로 동의한 경우에만 요청합니다.

이 프로젝트는 가스앱, SK E&S 또는 각 지역 도시가스 공급사의 공식 서비스가 아닙니다. 프로젝트 아이콘도 공식 회사 로고가 아닙니다.

에너지톡 연결은 사용자가 직접 가져온 세션 토큰을 HA 설정에 저장하고 공식 에너지톡 서버에만 전송합니다. 주소 선택을 바꾸거나 카카오 인증 코드를 교환하지 않습니다. 대성·해양에너지 로그인 세션은 공급사별로 분리하며 진단 자료에 로그인 정보·토큰·원본 응답을 포함하지 않습니다.
