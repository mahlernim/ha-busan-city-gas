# 함께 사용해 보실 분을 찾습니다

[처음으로](../README.md) · [설치 안내](installation.md)

부산도시가스를 이용하고 Home Assistant를 사용 중이라면 참여하실 수 있습니다. 개발 지식은 필요하지 않습니다.
아직 다양한 계정·휴대폰 환경에서 확인이 필요한 첫 공개 버전입니다. 중요한 검침 제출이나 결제는 기존 방법을 계속 이용해 주세요.

## 이렇게 확인해 주세요

1. 설치 전 Home Assistant 백업을 만듭니다.
2. 처음에는 센서·알림을 건너뛰고 로그인과 요금 조회만 해봅니다.
3. 최근 고지금액과 사용기간이 홈페이지와 맞는지 확인합니다.
4. 센서가 있다면 연결하고 실제 계량기 숫자를 입력해 추정값 변화를 봅니다.
5. Android 휴대폰으로 알림 테스트를 보내 수신·버튼·본문 이동을 확인합니다.
6. 접수 상태 조회를 사용했다면 홈페이지 표시와 같은지 확인합니다. **이 기능은 제출하지 않습니다.**

## 이런 후기가 도움이 됩니다

- 설치와 로그인 과정에서 막힌 곳이 있었나요?
- 센서 선택이나 계량기 숫자 입력 설명이 이해됐나요?
- 요금·사용기간이 홈페이지와 같았나요?
- 휴대폰 알림과 화면은 편하게 사용할 수 있었나요?
- 오류가 있었다면 어떤 버튼을 눌렀을 때 어떤 문구가 나왔나요?

[사용 후기·오류 제보 남기기](https://github.com/mahlernim/ha-busan-city-gas/issues/new?template=test-report.yml)

잘 된 결과도 환영합니다. 통합 버전과 Home Assistant 버전을 함께 알려주세요.
게시물은 공개됩니다. 아이디·비밀번호·계약번호·주소·원본 고지서는 보내지 말고, 화면 사진은 개인정보를 가린 뒤 올려주세요.
