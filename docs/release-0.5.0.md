# SK E&S 도시가스 v0.5.0

부산도시가스에 더해 코원·충청·영남 구미·포항·전남·강원·전북에너지서비스를
지원합니다. 설정에서 공급사를 선택하면 해당 포털 경로와 회사 코드로 계약,
고지서, 열량과 자가검침 상태를 조회합니다.

주택용 예상요금은 공급사별 공개 요금표를 사용합니다. 구미의 522 MJ 구간과
코원의 서울·경기 요금 지역을 구분하며, 요금표를 명확하게 해석하지 못하면
확정 고지서를 유지한 채 예상금액만 표시하지 않습니다.

직접 제출과 조건부 자동 제출도 선택한 공급사 경로를 사용합니다. 자동 제출은
기본적으로 꺼져 있으며, 기존과 같이 접수 기간·실측 상태·중복 여부를 확인하고
전송 후 접수값을 재조회합니다. 불명확한 요청은 자동으로 재전송하지 않습니다.

기존 부산 사용자는 계정을 다시 등록할 필요가 없습니다. 통합 domain과 계약·엔티티
식별자, 저장된 고지서·보정·제출 이력 및 기존 제출 동의를 유지합니다. 통합과
사이드바의 표시 이름만 **SK E&S 도시가스**로 바뀝니다.

부산 외 공급사는 공통 공개 포털 구조와 개인정보가 없는 합성 응답으로 검증했습니다.
각 지역의 실제 고객 계정이나 실제 자가검침 접수를 개별 검증했다는 뜻은 아닙니다.
