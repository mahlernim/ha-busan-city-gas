# 부산도시가스 v0.4.0

센서 없이도 검침값을 추정하고, 실제 계량기 숫자를 주기적으로 확인하여 최근 사용 추세를 반영할 수 있습니다.

- 센서 없이 시작할 때에도 현재 계량기 숫자를 선택적으로 입력합니다.
- 과거 사용량과 유효한 최근 실측으로 추정하며 자료 부족·학습 기간·실측 비중을 표시합니다.
- 재시작 후 정상 센서 연결을 마지막 저장 시각부터 최대 120초 기다립니다. 대기 중 제출을 차단하며 기존 공백을 임의로 지우지 않습니다.
- **제출 내역 확인**, **요금·검침 정보 업데이트** 버튼 설명과 한국어 사용 안내를 정리했습니다.
- Android 알림, 설정 순서, ESP32·리드 센서 참고 사진을 추가했습니다.

## 업데이트

HACS에서 다운로드한 뒤 Home Assistant를 재시작하세요. 계정을 다시 등록할 필요는 없습니다. 기존 계약·엔티티·실측·고지서·제출 이력·알림 설정과 제출 동의를 유지합니다. 자동 제출이나 과거 추정값 제출을 새로 켜지 않습니다.

이미 표시된 측정 공백은 실제 숫자를 확인하여 보정해야 합니다. 모델 검증은 계산·연속성·복구·권한을 다루며, 실제 가정에서 정확도가 개선되었다는 주장은 하지 않습니다. 외부 제출 테스트는 모의 서버에서 수행합니다.

최소 Home Assistant 2026.7.4가 필요합니다. CI 검증 대상은 2026.7.4 및 2026.8.3입니다. 이외 모든 버전의 호환성을 보장한다는 뜻은 아닙니다. HACS 사용자 지정 저장소로 설치하며 기본 목록 등재와는 별개입니다.
