아이디·비밀번호로 시작하고, 센서와 휴대폰은 필요할 때 연결하세요.

HACS에서 설치하고 Home Assistant를 재시작한 뒤 진행합니다.
1 홈페이지 계정으로 로그인

1/5 · 부산도시가스 로그인

부산도시가스 홈페이지의 회원 아이디·비밀번호를 입력하세요. 연결된 계약을 자동으로 찾습니다.

아이디gas_user_example
비밀번호••••••••••••

고객번호·계량기 번호·쿠키는 입력하지 않습니다.

다음 → 로그인과 연결 계약 확인 중…
계약 1개는 자동 선택되어 바로 센서 연결로 이동합니다. 여러 계약이 연결된 경우에만 선택 화면이 추가됩니다.
2 누적 사용량 센서 선택 선택 사항

2/5 · 가스 사용량 센서 연결 (선택)

가스를 사용할 때마다 증가하는 원본 누적 센서를 선택하세요. m³ 단위의 누적 센서만 표시합니다.

누적 가스 사용량 센서가스 누적 사용량 · m³ ▾
sensor.example_gas_total

일일·월간 사용량이나 기존 ‘추정 검침값’ 센서를 선택하지 마세요.

센서가 없으면 비워두고 다음으로 진행하세요. 공식 고지서 조회만으로도 사용할 수 있습니다.

센서 없이도 다음 화면에서 실제 계량기 숫자를 선택적으로 입력합니다. 과거 사용량과 실측 추세로 추정하며, 센서는 나중에 연결해도 됩니다.
3 실제 계량기 숫자 입력 선택 사항

2/5 · 검침 기준값 설정

현재 계량기에 보이는 누적 숫자를 입력하세요. 이번 달 사용량이 아닙니다.

현재 계량기에 보이는 누적 숫자 (m³)128.6

센서가 있으면 현재 센서값과 함께 저장합니다. 센서가 없으면 확인 시각과 함께 기록하여 추정의 기준으로 사용합니다.

가져올 기존 값: 없음

생략해도 공식 조회는 시작합니다. 센서가 없으면 날짜·계량기가 맞는 공식 기준을 찾고, 사용할 기준이 없으면 실제 숫자 입력을 안내합니다.

이전 보정 기록이 있는 환경에서는 ‘기존 보정값 가져오기’가 표시됩니다. 직접 입력 대신 사용할 수 있습니다.
4 알림 받을 휴대폰 선택 선택 사항

3/5 · 알림 받을 휴대폰과 일정 (선택)

Companion App에 등록된 휴대폰을 선택하고 필요한 알림만 켜세요. 여러 대를 선택할 수 있습니다.

알림은 기본 꺼짐이며, 체크해야 발송됩니다.
모든 시간은 Home Assistant 시간대를 따릅니다.

담당자 권한도 함께 부여됩니다. 선택한 휴대폰의 HA 사용자는 해당 계약을 보정하고 제출할 수 있습니다.
5 자동 제출 여부 결정

4/5 · 자가검침 제출 정책

자동 제출을 켜면 마감일의 설정 시각 이후, 미제출 상태를 확인하고 검침값을 실제로 전송합니다.

마감일 미제출 시 자동 제출
마감일 자동 제출 시간22:00

기본은 꺼짐입니다. 첫 사용은 직접 제출한 뒤 홈페이지에서 접수값을 확인하는 것을 권장합니다.

알림을 켜는 것과 자동 제출에 동의하는 것은 서로 다른 설정입니다.

센서 없는 이용자에게만 ‘과거 사용량 기반 추정값 제출 허용’이 추가로 표시됩니다. 기본은 꺼짐입니다.
