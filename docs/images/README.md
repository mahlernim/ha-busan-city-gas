# 문서 이미지 원본과 기준

- `onboarding-overview.html` → `onboarding-overview.png`: v0.4.0 설정 항목을 바탕으로 재구성한 모의 안내. HTML을 브라우저에서 열고 아래 PNG 생성 버튼으로 2배 크기 이미지를 만듭니다. 로그인·제출 성공 증거가 아닙니다.
- `android-submission-notification.png`: Android Companion App 알림 화면. 촬영용 버튼은 실제 제출을 실행하지 않았습니다.
- `reed-sensor-installation.jpg`: 사진 제공자가 기기번호를 가린 설치 참고 사진의 축소 사본(750×1000). 원본 내용·배선은 변경하지 않았습니다. 공개 전 제공자가 식별정보 가림을 확인했습니다. 촬영 위치 메타데이터는 포함하지 않습니다. 설치 안전성이나 정확도 검증 자료가 아닙니다.
- `overview.png`, `overview-dark.png`: 실제 패널 코드에 예시 데이터를 넣은 화면. 재현 페이지는 `tests/preview.html`이며 `dark`, `mobile`, `sensorless`, `waiting`, `missing` 쿼리로 화면 상태를 확인할 수 있습니다.

설정·문구를 바꾸면 소스와 결과 이미지를 함께 갱신합니다. 실제 고객 정보·인증정보가 든 원본은 이 저장소에 보관하지 않습니다.
