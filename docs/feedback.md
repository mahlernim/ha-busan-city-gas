# 문의와 오류 제보

[처음으로](../README.md) · [설치 안내](installation.md)

사용 중 불편한 점이나 개선 의견을 GitHub에 남겨주세요. 개발 지식은 필요하지 않습니다.

## 문의하기 전에

1. [문제 해결 안내](troubleshooting.md)에서 해당 증상을 확인하세요.
2. 통합 버전과 Home Assistant 버전을 확인하세요.
3. 누른 버튼, 기대한 결과, 실제로 나타난 문구를 적어주세요.

제출 결과가 불명확하면 반복해서 누르지 말고 **접수 상태만 확인** 또는 선택한 도시가스 공급사 홈페이지에서 확인하세요. 오류 재현을 위해 실제 검침값을 다시 전송할 필요는 없습니다.

## 이런 정보를 알려주세요

- 설치와 로그인 과정에서 막힌 곳이 있었나요?
- 센서 선택이나 계량기 숫자 입력 설명이 이해됐나요?
- 요금·사용기간이 홈페이지와 같았나요?
- 휴대폰 알림과 화면은 편하게 사용할 수 있었나요?
- 오류가 있었다면 어떤 버튼을 눌렀을 때 어떤 문구가 나왔나요?

[사용 후기·오류 제보 남기기](https://github.com/mahlernim/ha-busan-city-gas/issues/new?template=test-report.yml)

개선 의견도 환영합니다. 통합 버전과 Home Assistant 버전을 함께 알려주세요.
새 공급사 연결에서는 공급사 이름과 실패 단계(본인 인증·계약 선택·요금 조회·접수 확인)도 적어 주세요. 설정 → 기기 및 서비스에서 이 통합의 진단 다운로드를 첨부하면 버전·상태 요약을 확인할 수 있습니다. 진단에는 계정정보·계약번호·검침값·원본 응답을 포함하지 않습니다.
게시물은 공개됩니다. 아이디·비밀번호·계약번호·주소·원본 고지서는 보내지 말고, 화면 사진은 개인정보를 가린 뒤 올려주세요.
