# 부산도시가스 v0.4.1

Home Assistant 종료 시 센서의 정상적인 연결 해제를 측정 공백으로 기록하던 문제를 수정했습니다. 센서를 연결하여 사용하는 이용자에게 영향을 줄 수 있어 업데이트를 권장합니다.

- 종료·최종 저장 단계에서는 마지막 정상 센서값과 시각을 유지합니다.
- 재시작 후 대기 기한은 마지막 정상 센서 시각부터 120초입니다. 종료나 재시작으로 기한을 연장하지 않습니다.
- 정상 운영 중 결측·카운터 감소·기존 공백은 계속 실측 보정이 필요합니다.

HACS에서 업데이트한 뒤 Home Assistant를 재시작하세요. 계정 재등록은 필요 없습니다. 기존 설정·고지서·보정·제출 이력과 제출 동의는 유지됩니다.

**이미 표시된 측정 공백은 업데이트만으로 해제하지 않습니다.** 계량기의 실제 숫자를 확인하고 보정해 주세요. 특히 이전 버전에서 업그레이드하는 첫 종료 과정은 이전 코드가 처리하므로 한 번의 실측 확인이 필요할 수 있습니다. 검침값을 임의로 확인 처리하거나 자동 제출을 새로 활성화하지 않습니다.

Home Assistant 최소 지원 버전은 2026.7.4로 동일합니다. 온보딩과 화면 구성은 v0.4.0과 같습니다.
