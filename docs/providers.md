## 가스앱 · 실험적 지원

서울도시가스, 인천도시가스, 제주도시가스, JB, 대륜E&S, 예스코, 군산도시가스, 귀뚜라미에너지, 참빛도시가스 계열, 경동도시가스, MC에너지(목포도시가스), 미래엔서해에너지, 대화도시가스, 전북도시가스를 선택할 수 있습니다. 14개 브랜드가 18개 회사 코드에 대응합니다.

휴대폰 본인 인증과 문자 인증으로 연결합니다. 계약·고지서·검침 상태 조회와 검침값 제출을 구현합니다. 자가검침 서비스 가입이나 접수 채널 변경이 필요한 계약은 전용 화면에서 해당 변경에 동의한 뒤 진행하세요. 이 변경은 공급사 계정의 실제 서비스 상태에 영향을 줍니다.

## 삼천리 · 실험적 지원

홈페이지 회원 아이디·비밀번호로 연결하며 계약·고지서 조회와 자가검침 제출 경로를 제공합니다. 계약이나 접수 기간에 따라 서버가 온라인 검침을 허용하지 않을 수 있습니다.

## 에너지톡 · 실험적 지원

CNCITY에너지, 경남에너지, 서라벌도시가스, 지에스이는 에너지톡으로 연결합니다. 에너지톡에서 카카오 로그인하고 사용할 주소를 선택한 뒤 해당 세션 토큰을 입력합니다. 계약·사용량·검침 상태 조회와 검침값 제출을 구현했습니다. 토큰은 선택된 한 주소에 연결되며 만료 시 재인증이 필요합니다. [설정 방법](installation.md#에너지톡-세션-연결)

귀뚜라미에너지와 미래엔서해에너지는 이름 뒤에 **(에너지톡)**이 붙은 항목을 선택할 수 있습니다. 참빛 계열은 참빛원주, 참빛충북, 참빛영동, 참빛영동 동해지점, 참빛속초 중 공식 세션에 표시된 서비스를 선택하세요. 기존 가스앱 항목과 저장된 설정은 유지되며 자동으로 다른 채널로 바뀌지 않습니다. 같은 계약을 두 채널에 중복 등록하면 별도 항목이 생기므로 필요한 연결 하나를 선택하세요.

에너지톡이 현재 접수 가능 여부만 제공하므로 실제 마감일을 만들어 표시하지 않습니다. 직접 제출과 HA 자동화 액션을 사용할 수 있지만 내장 마감일 자동 제출은 비활성화합니다. 만료된 토큰이 확인되면 해당 클라이언트의 추가 요청을 중단하고 재인증 후 다시 연결합니다.

## 대성·해양에너지 · 실험적 지원

대성에너지, 대성청정에너지, 해양에너지는 각각 홈페이지 회원 아이디·비밀번호를 사용합니다. 계약·고지서·검침 상태 조회와 검침값 제출을 구현했습니다. 대성 계열은 로그인 뒤 실제 HTML의 계약 선택·고지서 표·검침 양식을 찾아 처리하므로 화면 구조가 다르면 구체적인 단계 오류로 중지됩니다. 해양에너지는 웹 프로토콜을 사용합니다. 모두 실제 고객 계정으로 검증되지 않은 실험적 연결입니다.

## 명성파워그린 · 미지원

[공식 고객지원 안내](https://www.myungsungpower.com/?act=board&bbs_code=notice&bbs_mode=view&bbs_seq=37)와 공개 사이트를 조사했으나 연동할 수 있는 고객 조회·자가검침 프로토콜을 찾지 못했습니다. 지원되는 것처럼 빈 연결을 제공하지 않으며 현재 30개 항목에 포함하지 않습니다. 고객용 앱 또는 접수 URL 제보가 있으면 추가할 수 있습니다.

부산은 실제 조회로 확인했습니다. 다른 지역과 새 연결은 공개 프로토콜과 합성 응답으로 검증했으며, 사용자 계정에서의 성공을 보장하지 않습니다. 새 공급사 지원은 실제 계정 검증을 기다리며 차단하지 않고 사용자 보고로 보완합니다. 공급사 이름만으로 접수 성공을 판단하지 않으며 계약·기간·제출값 확인을 거칩니다.

월 금액과 사용량만 제공되는 고지서도 보관합니다. 상세 요율·열량·청구기간 자료가 없으면 해당 예상값을 표시하지 않습니다. 예상요금은 확정 고지금액과 다를 수 있습니다.

자동 제출은 기본 꺼짐입니다. 직접 제출하거나 자동 제출에 동의한 경우에만 검침값을 보냅니다. 접수값을 재조회하고 결과가 불명확하면 자동으로 다시 보내지 않습니다. 첫 제출은 공급사 앱·홈페이지에서도 접수값을 확인해 주세요. 문제가 있으면 공급사 이름, 실패 단계, 개인정보를 지운 오류 메시지를 [제보](feedback.md)해 주세요.

표시 이름은 똑똑 자가검침 AI이며 기존 `busan_city_gas` 도메인·서비스·저장소 주소는 유지합니다. 기존 설치를 삭제하거나 다시 등록할 필요가 없습니다.
