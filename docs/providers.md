# 지원 도시가스 공급사

[처음으로](../README.md) · [설치](installation.md) · [개인정보](privacy.md)

이 통합은 같은 SK E&S 회원·요금 포털을 사용하는 다음 공급사를 지원합니다.

| 공급사 | 홈페이지 경로 | 주택용 예상요금 |
| --- | --- | --- |
| 부산도시가스 | `busan` | 516 MJ 구간 |
| 코원에너지서비스 | `koone` | 서울·경기 선택 |
| 충청에너지서비스 | `cheongju` | 지원 |
| 영남에너지서비스 구미 | `gumi` | 522 MJ 구간 |
| 영남에너지서비스 포항 | `pohang` | 지원 |
| 전남도시가스 | `jeonnam` | 지원 |
| 강원도시가스 | `gangwon` | 지원 |
| 전북에너지서비스 | `jeonbuk` | 지원 |

서울도시가스, 예스코, 삼천리, 전북도시가스 등은 다른 시스템을 사용하므로 이
목록에 포함되지 않습니다. 같은 시·도 안에도 공급사가 여러 곳일 수 있으므로
주소만으로 선택하지 말고 청구서의 회사명을 확인하세요.

8개 공개 로그인 페이지는 같은 로그인 필드와 처리 구조를 사용하며, 공개 열량
조회는 공급사 회사 코드를 받습니다. 부산 계정은 실제 조회로 확인했습니다.
다른 공급사는 공개 페이지와 개인정보가 없는 합성 응답으로 검증했으므로 실제
계약의 응답이 다를 수 있습니다. 통합은 알 수 없는 응답을 추정해서 처리하지 않습니다.

예상요금은 선택한 취사·개별난방·중앙난방 등 주택용 유형의 참고값입니다. 요금표나 계약 유형을 고유하게 해석하지 못하면
예상금액만 표시하지 않으며, 공급사에서 받은 확정 고지서와 사용량은 그대로 보여줍니다.
자가검침 제출은 기본적으로 꺼져 있고 사용자가 확인하거나 자동 제출에 별도로
동의한 경우에만 실행합니다. 응답만으로 성공이라 하지 않고 같은 계약의 접수값을
재조회하며, 결과가 불명확하면 자동으로 다시 보내지 않습니다.
